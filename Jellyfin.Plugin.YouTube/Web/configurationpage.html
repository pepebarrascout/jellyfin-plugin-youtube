YouTube Streaming

Reproduce videos de YouTube como Series en Jellyfin sin descargarlos al disco. No requiere API key de YouTube — usa yt-dlp para todos los metadatos.

Configuración general

Ruta al binario de yt-dlp. Se usa tanto para metadatos de canal como para resolver URLs de stream.
Dentro de Docker monta yt-dlp del host, por ejemplo: -v /usr/bin/yt-dlp:/usr/local/bin/yt-dlp:ro
Y luego configura esta ruta como /usr/local/bin/yt-dlp
Donde se escriben los archivos .strm. Agrega esta ruta como biblioteca tipo "Shows" en Jellyfin. Default: /config/youtube_plugin (dentro del contenedor Docker)
No debe coincidir con el puerto de Jellyfin (8096). Default: 8585.
Los archivos .strm apuntan a un proxy local que resuelve las URLs de YouTube bajo demanda. Desactiva solo si sabes lo que estás haciendo.

Agregar canal

Al agregar un canal se inicia la sincronización en segundo plano con yt-dlp. Los archivos .strm aparecen en ~30 segundos.
